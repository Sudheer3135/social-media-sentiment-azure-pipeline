# Social Media Sentiment Analysis Pipeline

## Built on Microsoft Azure

### Overview

This project implements an end-to-end cloud data pipeline to analyze sentiment from social media data using Azure services.

### Architecture

CSV → Azure Blob Storage → Azure Data Factory → Azure Synapse Analytics → Power BI

### Results

* Total Posts: 49,991
* Positive: 25,012 (50.1%)
* Negative: 24,979 (49.9%)

### Technologies Used

* Microsoft Azure (ADF, Synapse, Blob Storage)
* Python (Pandas)
* SQL
* Power BI
